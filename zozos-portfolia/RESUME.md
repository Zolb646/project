# Editing the resume

Edit `public/resume.html` for content and `public/resume.css` for appearance. The files are standalone: open the HTML directly in a browser, or visit `/resume.html` when the portfolio is running.

Use **Print / Save as PDF** and choose A4, 100% scale, no margins, background graphics enabled, and browser headers and footers disabled. Save the result as `public/Zozo-resume.pdf`; the portfolio's existing download links already use this path.

Keep the resume to one page and inspect the print preview after changing content. The erxes Frontend Engineer role starts on June 2, 2026.
